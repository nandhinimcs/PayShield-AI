# PayShield AI
### Verify Before Payment. Recover With Confidence.

PayShield AI is an AI-powered payment safety assistant designed to help users verify payment details and prepare for PayPal disputes.

## Features
- Purchase consistency checking
- Payment detail comparison
- Dispute assistance
- Evidence checklist
- PayPal Sandbox checkout

## Technologies
- React
- Vite
- Node.js
- Express
- PayPal Sandbox
- Agentverse

## Disclaimer
This is a hackathon prototype. It does not guarantee fraud detection, refunds, or dispute outcomes.
